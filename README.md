# College Management System

MERN-based College Management System using React.js, Node.js, Express.js and MongoDB.

## Planned modules
- Public: Home, About, Contact, Login
- Admin: Students, Teachers, Notices, Achievements, Results, Search, Events
- Student: Details, Present Academic Details, Previous Academic Details, Assignments
- Teacher: Details, Teaching Details, Attendance & Marks, Leave Application

## Development rule
Each module is developed separately, explained, tested, and then connected to the next module.
